# Annamneedi Satyanarayana — Personal Portfolio

A modern portfolio website for Annamneedi Satyanarayana, showcasing full-stack development work, backend systems, AI-enabled products, cloud-focused solutions, education, certifications, and professional experience.

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Local Development

```bash
npm install
npm run dev
```

The app runs locally in development mode using Vite.

## Production Build

```bash
npm run build
```

This generates the production-ready files in the dist folder for deployment or local preview.

## Project Structure

- src/ — application source, components, data, and pages
- public/ — static assets and site metadata
- index.html — application entry and document metadata

## Notes

This project is a standalone portfolio for VS Code and npm.
